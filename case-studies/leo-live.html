LEO·LIVE Satellite Tracker

React + shadcn/ui + satellite.js — visualisasi orbit satelit real-time dengan TLE data, globe 3D, dan kontrol simulasi waktu.

TECH: React 19 · TypeScript · Vite · Tailwind v4 · shadcn/ui · satellite.js · Three.js-based GlobeEngine

FEATURES:
• Real-time TLE propagation via satellite.js
• 3D globe with WebGL2 (auto-detect fallback)
• 30+ satellite group layers
• Orbital path + ground track rendering
• Time simulation (fast-forward/rewind)
• Search, filter, detail panel telemetry
• Deep link via URL param (?sat=XXXXX)

React app — butuh npm run build untuk live demo.
